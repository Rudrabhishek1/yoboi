## 2024-07-04 - Batching CustomPainter path operations
**Learning:** In Flutter, issuing multiple consecutive `canvas.drawLine` calls can have overhead. It is generally faster to batch these line drawing operations into a single `Path` object and draw them together with `canvas.drawPath`, but when converting to `drawPath` you must explicitly set `paint.style = PaintingStyle.stroke` immediately prior to the draw call. Even if you previously set the style via cascade operators, failure to do so explicitly right before `drawPath` can cause automated tests or visual checks to falsely flag a regression (fill instead of stroke).
**Action:** When optimizing line drawing with `drawPath`, always explicitly assign `paint.style = PaintingStyle.stroke` right before calling `canvas.drawPath(path, paint)`.
