## 2024-05-30 - Fix insecure deserialization in remote config payloads
**Vulnerability:** The app parsed remote JSON payloads from Firebase Remote Config directly into a list of maps using `jsonDecode(jsonString)` and then mapping `as Map<String, dynamic>` without first verifying the types. This creates a risk of `TypeError` crashes if the payload is malformed or manipulated.
**Learning:** Dart's dynamic typing with JSON requires explicit runtime type checking (using `is`) before treating decoded objects as specific collection types (e.g., `List` or `Map<String, dynamic>`) to prevent unexpected application crashes.
**Prevention:** Always verify the top-level structure of decoded JSON (e.g., `if (decoded is! List) return;`) and explicitly check the type of elements before casting (e.g., `decoded.where((e) => e is Map<String, dynamic>).cast<Map<String, dynamic>>().toList()`). Additionally, harden factory constructors to safely handle invalid or missing values in maps.
