## 2026-05-06 - Adding Tooltips for IconButtons
**Learning:** In Flutter, the `tooltip` property on `IconButton` widgets provides essential hover text context and also automatically acts as an ARIA label for screen readers. Using dynamic tooltips based on state (e.g., toggling a favorite) significantly enhances accessibility.
**Action:** Consistently apply `tooltip` strings to all icon-only buttons to ensure clear intent for screen reader users and web/desktop users.
