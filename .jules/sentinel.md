## 2024-05-23 - Insecure Deserialization of Remote Configuration
**Vulnerability:** The application was directly casting a dynamically decoded JSON structure from Firebase Remote Config into a `List<dynamic>` and then mapping its elements to `CustomFormulaData` using standard type assumptions (e.g., `map['id']` as String, `List<String>.from(map['inputLabels'])`).
**Learning:** This approach causes critical runtime `TypeError` crashes if the remote configuration provides malformed JSON, a different data structure (like a `Map`), or if fields contain unexpected types. It allowed untrusted data structures to bypass validation.
**Prevention:** Always verify the top-level structure of remote JSON payloads (e.g., `is List`) and ensure list elements are `Map<String, dynamic>`. Harden model factories (like `fromMap`) by using safe conversion operators (e.g., `?.toString() ?? ''`) and explicit type checking for collection fields to provide fallback defaults and prevent application crashes.
