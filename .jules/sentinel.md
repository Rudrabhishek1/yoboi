
## 2026-05-28 - Insecure Deserialization in Remote Configuration
**Vulnerability:** The app fetched remote JSON payloads via Firebase Remote Config and parsed them directly into strongly-typed model structures using `jsonDecode().map().toList()` without verifying the top-level structure or confirming map fields before explicitly casting them (e.g. `as List`).
**Learning:** In Dart/Flutter, blindly casting `dynamic` outputs from `jsonDecode()` based on implicit trust in external structural payloads can lead directly to fatal `TypeError` crashes across the app. If a malicious or malformed payload is intercepted, modified, or incorrectly formed (e.g., passing primitives instead of iterables, or generic maps without required structure keys), the app fails destructively instead of gracefully.
**Prevention:** Always implement explicit structural validation (e.g. `if (decoded is! List)`) when parsing unknown JSON sources. Use `whereType<Map<String, dynamic>>()` to filter out invalid objects before mapping, and use safe navigational operators `?.toString() ?? ''` and explicit collection checks `map['key'] is List` directly inside factory constructors (`fromMap`) to defensively type-check and sanitize fields during object instantiation.
