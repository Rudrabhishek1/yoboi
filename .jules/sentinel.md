## 2024-05-24 - Insecure Deserialization of Remote Config Payloads
**Vulnerability:** The application was directly parsing JSON payloads from Firebase Remote Config (`jsonDecode`) into a `List<dynamic>` without verifying the top-level structure, and directly mapping unverified dynamic map properties (like lists and strings) in `CustomFormulaData.fromMap`.
**Learning:** Dart's dynamic typing during JSON deserialization can lead to immediate application crashes (`TypeError` exceptions) when external sources supply malformed data structures (e.g., passing a number instead of a string, or an object instead of an array). This can be used as an application-level Denial of Service if the remote config is compromised or misconfigured.
**Prevention:** Always explicitly verify the top-level structure (e.g., `is List`) and use `.whereType<Map<String, dynamic>>()` for collections. Harden model factory constructors with safe conversion operators (e.g., `?.toString() ?? ''`) and type checking (e.g., `is List`) before attempting to use the values.
