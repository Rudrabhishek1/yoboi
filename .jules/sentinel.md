## 2025-02-14 - Fix Insecure Deserialization of Remote Config Formulas
**Vulnerability:** The application blindly casts elements of a remote JSON array into `Map<String, dynamic>` and passes them to `CustomFormulaData.fromMap` without explicit type checking in `firebase_service.dart`. Furthermore, `CustomFormulaData.fromMap` assumes specific types for its fields (like `id` being a String, `inputLabels` being a List) which can crash the app (`TypeError`) if malformed data is injected into Firebase Remote Config or local SharedPreferences.
**Learning:** Dart's dynamic typing with JSON decoding requires explicit runtime type checks (`is`) before casting or extracting fields, as missing fields or incorrect types will cause unhandled `TypeError` exceptions, crashing the app.
**Prevention:** Always use explicit type checking (e.g., `map is Map<String, dynamic>`, `map['field'] is List`) and safe conversion operators (`?.toString() ?? ''`) when parsing external JSON data into Dart objects to fail safely instead of crashing.
