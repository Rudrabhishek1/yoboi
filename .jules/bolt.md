## 2024-05-08 - Optimizing CustomPainter for Static Grid Rendering
**Learning:** In Flutter, allocating `Paint` objects inside the `paint()` loop and drawing many individual elements (like lines in a grid) using `canvas.drawLine` creates significant CPU overhead and triggers frequent garbage collection, especially on complex or large canvases. Additionally, background `CustomPaint` widgets can be needlessly repainted due to layout changes in parent widgets.
**Action:** Always pre-calculate and cache expensive objects like `Paint` as `static final` members. Consolidate multiple distinct drawing commands into a single `Path` and draw it with `canvas.drawPath()`. Finally, wrap static or independent `CustomPaint` sub-trees in a `RepaintBoundary` to shield them from parent-induced repaints.
